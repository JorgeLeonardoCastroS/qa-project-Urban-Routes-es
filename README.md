# Proyecto Urban Routes pruebas automatizadas.

## 1. Nombre del proyecto:

Proyecto Urban Routes pruebas automatizadas.

## 2. Descripción del proyecto:

En este proyecto se está probando el cálculo de una ruta, selección de una tarifa y solicitud del servicio con otras solicitudes adicionales.

### Pruebas automatizadas para los parámetros:
1. se está probando Configurar la dirección (esta parte se ha escrito para ti como ejemplo).
2. se está probando seleccionar la tarifa Comfort.
3. se está probando Rellenar el número de teléfono.
4. se está probando Agregar una tarjeta de crédito.
5. se está probando Escribir un mensaje para el controlador.
6. se está probando Pedir una manta y pañuelos.
7. se está probando Pedir 2 helados.
8. se está probando que Aparece el modal para buscar un taxi.
9. se está probando Esperar a que aparezca la información del conductor en el modal (opcional).

- Necesitas tener instalados los paquetes pytest y requests para ejecutar las pruebas.
- Ejecuta todas las pruebas con el comando pytest.
- Ejecuta las pruebas automatizadas.

## 3. Tecnologías usadas

- Selenium
- Pycharm 
- Pytest
- Lenguaje de programación Python 
- Libreria requests de Python
- Patron de programación POM (Page Object Model)
